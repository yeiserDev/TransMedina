# Icono de TransMedina

`icon.svg` combina el camión de Lucide usado en el calendario y la R del logotipo de Ripley. Se mantiene el fondo crema y la tinta negra de la aplicación. La R se extrajo del SVG del encabezado oficial de https://simple.ripley.cl/ (2026-10-20), con su geometría original; Lucide está publicado bajo licencia ISC.

PNG opacos derivados del SVG: 192 y 512 px para el manifiesto, 180 px para `apple-touch-icon` y 32 px para el navegador. El favicon de `src/app/favicon.ico` contiene la versión de 48 px. El contenido principal queda centrado en la zona segura de los iconos adaptables.
